# 2026 AI 트렌드 — 말하는 AI에서 일하는 AI로

## 자료 읽는 법 — 신뢰도 표기

2026년 AI 뉴스는 출처끼리 수치와 날짜가 엇갈리는 경우가 많습니다. 슬라이드의 모든 그래프·표 아래에 출처와 신뢰도를 적었습니다.

| 표기 | 뜻 |
|---|---|
| [공식] | 공식 보고서·기관 발표·학회 공지·법령 |
| [보도] | 주요 언론·업계 보도 |
| [주장] | 기업 자체 발표, 독립 검증 전 |
| [추적] | 2차 집계 사이트, 출처끼리 엇갈림 |
